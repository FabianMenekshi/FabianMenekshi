## 🚀 Featured Projects

### 📦 [Olist Delivery Performance: BI Dashboard](https://github.com/FabianMenekshi/olist-delivery-bi)

An end-to-end analytics project studying delivery performance in the Brazilian **Olist e-commerce dataset**.

- Built a reproducible pipeline with **PostgreSQL, Python, Docker, and Streamlit**
- Created an analytical order-level data model with data-quality validation
- Analyzed geographical and temporal patterns in late deliveries
- Connected delivery outcomes with customer reviews
- Built an interactive dashboard for exploring delivery KPIs

**Topics:** PostgreSQL, Python, Streamlit, Docker, Data Engineering, BI, Analytics

### 📊 [Data Science Salaries: US West Coast](https://github.com/FabianMenekshi/Data_Science_Salaries-West_Coast)

A statistical modeling project studying which characteristics of data-science job listings are associated with salary differences on the US West Coast.

- Built a custom dataset from online job postings
- Used **NLP** to extract skills and job requirements
- Developed interpretable regression models in **R**
- Studied the effects of experience, geography, skills, and education
- Investigated whether doctorate-level education is associated with higher salaries

**Topics:** Statistics, Regression, NLP, Python, R, Data Collection, Hypothesis Testing

### 🧠 [Parameter Golf: LLM Architecture & Quantization](https://github.com/FabianMenekshi/ML_and_AI_project)

An ablation study inspired by OpenAI's **Parameter Golf Challenge**, focused on improving a GPT language model under strict compute and memory constraints.

- Explored **Parallel Residuals, Depth Recurrence, and attention output gating**
- Implemented **mixed INT6/INT8 quantization** and quantization-aware training
- Reduced validation BPB from **1.3101 to 1.2812**
- Final compressed model size: **15.36 MB**
- Experiments conducted under a fixed **5,000-iteration / single A100 GPU** budget

**Topics:** Transformers, LLMs, Quantization, PyTorch, Model Compression, Deep Learning

---

### 🧪 [Hypoxia Classification from RNA Sequencing Data](https://github.com/FabianMenekshi/AI_LAB_2025)

A machine-learning study using high-dimensional **RNA-sequencing data** to classify mammary epithelial cells as hypoxic or normoxic.

- Analyzed **SmartSeq and DropSeq** datasets
- Applied feature selection and dimensionality reduction
- Explored unsupervised structure using clustering techniques
- Trained a stacking classifier combining **SVM, KNN, MLP, and Logistic Regression**
- Investigated how preprocessing and sequencing technology affect predictive performance

**Topics:** Machine Learning, Bioinformatics, RNA-seq, Classification, UMAP, Ensemble Learning

---

### 🧬 [Anatomical vs Functional Organization of Neurons: MICRONS](https://github.com/FabianMenekshi/Neuroscience_Project)

A computational neuroscience project investigating whether anatomical communities formed by synaptic connectivity correspond to functional neural representations.

- Built directed weighted graphs from **MICRONS** connectomics data
- Applied **Louvain, Leiden, and Infomap** community detection
- Compared anatomical structure with functional embeddings from neural digital-twin models
- Used **PCA, UMAP, CEBRA, K-Means, and Gaussian Mixture Models**
- Found non-trivial alignment between anatomical communities and functional representation similarity

**Topics:** Computational Neuroscience, Graph Analysis, Community Detection, Representation Learning, UMAP, CEBRA
